# 白板性能与 dim0 功能

## 使用

- 在白板「更多工具 → dim0 手绘图形」插入标签、思考云、胶囊、叠层矩形、叠层椭圆、叠层菱形或柔边菱形。图形可编辑、缩放、旋转、绑定文字、复制和撤销。
- 新绘制的箭头使用 dim0 的轮廓与笔刷线条。属性面板可选直线、贝塞尔曲线、折线，以及空心、实心或倒钩箭头。已有箭头可勾选「dim0 箭头」；外部导入的旧样式保留，直至用户修改。
- 选中 AI 连线后，中间显示固定 32 像素的垃圾桶按钮。按钮支持文字提示和键盘焦点；移除可撤销，只读白板或锁定目标节点禁止移除。AI 连线仍存于节点的 `links`。
- 「更多工具」和右键菜单提供四个方向的自动排列。有选区时排列选区，无选区时排列全板。组合、画框及其内容整体移动，锁定单元保持不动。循环连线保留，节点排到独立一列。
- 「更多工具 → 大纲转思维导图」按每行一个主题、缩进表示子主题生成可编辑图形，支持标题与项目符号。整次插入为一步撤销。
- `Ctrl+F` 打开白板搜索。搜索文字、图形标签、AI 指令/文本结果、名称、链接和 ID；不截断结果。上下键选择，回车定位，Esc 关闭。

## 文件兼容

继续使用 `.excalidraw` / `.excalidraw.svg`。新增轮廓以标准矩形元素加
`freefolioShape` 字段保存，箭头以标准线条元素加 `freefolioDim0Arrow` 保存。
FreeFolio 的 SVG、PNG 和 PDF 使用同一套几何输出。外部编辑器若不识别扩展字段，
可能只显示基础矩形或标准箭头；需要保持外观时使用 SVG/PNG/PDF 导出。
未知 FreeFolio 图形类型会报错，不静默转换成矩形。

## 来源与实施边界

固定来源与许可见 [dim0](../third_party/dim0/README.md) 和
[canvas-harness](../third_party/canvas-harness/README.md)。轮廓、箭头端点和笔刷通过
执行上游源码生成的夹具核对。排列采用原生算法，沿用 dim0 的方向与间距约定，
不宣称与 Dagre 的交叉边优化结果相同。本次未引入网页界面、在线协作或代码运行服务。

## 性能核查方法

1. `BenchmarkBoardResize` 测量一次连续缩放事件，排除界面、磁盘和网络。
2. `BenchmarkBoardAILinks` 测量未变化的 200 节点图的连线几何查询。
3. `BenchmarkWhiteboardFrame` 比较同一场景的单独白板与完整应用。使用
   `tools/perf overlay` 排除测试用软件绘制，先让打开动画结束，再测稳定帧。
   两种界面可用画布面积不同，结果用于定位开销，不用于推算真实帧率。

已确认并处理：缩放/旋转每次移动克隆全场景；AI 节点平移重新解析内容；
连线几何多次重建；不可见连线仍生成绘制路径；卡片插槽和文字缓存键反复分配。
视口平移、缩放不生成内容撤销记录，完成的编辑才触发文档变更。

稳定帧不能代表所有用户场景。GPU、显示器呈现、超大图片解码和实际用户白板
未由这些无窗口测量覆盖。本地产物报告保存本次机器上的测量数据。

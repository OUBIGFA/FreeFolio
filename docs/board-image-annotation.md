# AI 节点图片查看与标注

选中图片输入节点或已有图片结果的生成节点，点击 **查看图片** 或 **标注图片**。双击节点的图片预览也可打开独立窗口。同一节点的不同历史图片分别查看；相同图片再次打开时聚焦已有窗口。

查看窗口打开时直接适应画布，支持滚轮缩放、抓手拖动和实际大小。窗口内的图片、空白区域和控件按各自用途响应，不会因为点击空白而关闭。Windows 查看模式下，鼠标点击整个窗口之外并使其失去焦点时关闭；单纯使用 Alt+Tab 切换窗口不关闭。其他平台使用关闭按钮或 Esc。进入标注模式后不自动关闭，有未保存内容时沿用保存提示。原图的裁剪与水平/垂直翻转保留。只读白板和锁定节点允许查看，不能保存标注。

标注复用 FreeFolio 已移植的 Excalidraw/dim0 白板引擎：矩形、椭圆、箭头、直线、画笔、文字、橡皮、选择、颜色、线宽、不透明度，以及撤销和重做。底图保持锁定。深色界面中标注颜色与最终图片一致。

- **保存为参考图**：渲染标注副本并在原节点旁新增图片输入节点。
- **用于生图**：保存参考图，同时新增已连好的图像生成节点，并填入可编辑的标注改图指令。用户点击“运行节点”后才发送生成请求。
- **关闭窗口**：有未保存标注时，可保存、放弃或继续编辑。输入法仍在组字时先完成输入，避免把候选文字写入图片。

副本为普通 PNG 附件，通过现有附件目录规则创建，不覆盖原图，也不改变原节点的结果历史和连线。新增节点组合是一次可撤销操作。导出严格裁到图片范围，不包含白板留白或可编辑场景元数据；最长边最大 4096 像素，较小图片不放大。原图分辨率不变。节点被删除、锁定、白板变为只读或正在运行时，停止向白板应用结果；已经写好的副本仍保留在附件中。

## 开源依据

2026-11-25 核对 [Excalidraw v0.18.1](https://github.com/excalidraw/excalidraw/releases/tag/v0.18.1)，提交 `a2ec2889babf7d2295469c6d90ebe77fae57df84`。该版本相对 v0.18.0 的主要变更是网页端 Mermaid 安全修补，未引入本功能需要的新图片标注算法。

本功能直接复用已有的原生移植：Excalidraw/Quiet.md 的场景、图像、选择、手绘、文字、缩放和撤销，以及 dim0/canvas-harness 的箭头绘制。固定来源与 MIT 许可见[白板设计](whiteboard-design.md)、[dim0 说明](whiteboard-dim0.md)及[第三方清单](../third_party/manifests/upstreams.json)。不引入 WebView、JavaScript 编辑器或新的图像运行时。

## 验证

无窗口回归覆盖导出像素与尺寸、裁剪翻转、滚轮缩放、底图保护、输入法候选拒绝、原图保留、一次撤销、只读/锁定限制、关闭提示，以及实际生图任务收到的图片字节。网络路径使用隔离测试服务或已有执行器测试，不调用真实付费模型。窗口截图使用同一套生产组件绘制。

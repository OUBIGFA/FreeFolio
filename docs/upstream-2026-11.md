# 数据库、文档包与本地 Agent

本轮能力来自 ArcMD v0.3.0–v0.5.1，固定对照提交为 `e62e05a30d8b58512a2b5a41973d38fb0637e8e0`。来源范围见 [第三方清单](../third_party/manifests/upstreams.json)，核查依据见 [核查报告](../references/upstream-review-2026-11-28.md)。

## 编辑与阅读

- “添加分屏”使用 `columns-2` 图标，在各类文件中独立显示。“分屏选项”使用三点菜单，提供分屏方向、均分和移动等操作。分屏后仍可通过当前分屏的按钮继续添加，文件浏览模式使用共用标题栏按钮；最多四个分屏，达到上限时按钮禁用。侧边栏文件保持原位置和层级，不隐藏文件或额外显示分屏组。文件浏览模式返回空间后恢复此前的空间分屏
- 页面缩放范围为 50%–200%。使用 Ctrl+=、Ctrl+-、Ctrl+0 或 Ctrl+滚轮；macOS 使用 Command。非 100% 时标题栏显示比例菜单，PDF 和白板保留各自的缩放操作
- Markdown 源码支持语法高亮、查找替换、缩进和分栏预览。源码保存保留原始文本；`.arcmd` 的 Markdown 导出保持只读
- Mermaid 支持 `stateDiagram`、`stateDiagram-v2`，可导出 HTML/PDF 或转换为可编辑白板
- 清除格式保留链接。文档属性继续默认显示为属性列表；“元数据源码”提供 YAML 查看和编辑

长文档目录跳转、数字开头公式与字面美元符号、Excel/WPS 等多格式剪贴板、浮层命中、Windows PDF 占用和特殊文件名均包含针对性回归。

## 多维数据库

使用“快速新建”或命令栏创建数据库。数据库以 `.db.md` 保存，支持文件夹记录、空间记录和内联记录。文件夹记录保存在普通 Markdown 文件中，属性放在 YAML 元数据中。

九种视图为表格、看板、日历、时间轴、列表、画廊、图表、动态流和表单。支持筛选、排序、分组、关联、汇总、公式、模板、CSV 与 Notion 导入及 CSV 导出。数据库可以作为关联视图嵌入文档。

`internal/database` 不依赖窗口。`internal/editor/dbview` 使用 MyGo 原生控件。应用层负责打开记录、保存、文件冲突、回收站备份和搜索引用；目录元数据、关联数据库及封面通过缓存与后台读取接入。

数据库配置与记录是不同文件。属性更新会检查记录的读取基线，外部修改后拒绝覆盖。历史恢复替换数据库配置并保留撤销，不覆盖独立记录文件。

## MDZip 文档包

在“更多 → 导出”选择“导出 MDZip (.mdz)”。FreeFolio 将正文与本地附件写入新文件，名称已存在时自动编号。图片、白板及白板 AI 历史媒体随副本打包；原文和原附件不改写。

打开 `.mdz` 后只能阅读。支持包内页面导航、搜索、图片、白板/PDF 查看和“一键解包另存为文档”。解包使用空闲目标名称，不覆盖现有文件。归档检查路径、重复条目、符号链接、压缩比及解压体积。EPUB 和 WebView 不属于本轮集成范围。

## 本地 Agent 接入

打开“设置 → 本地 Agent 接入”，复制 MCP 配置或安装技能包。安装只由点击触发。命令行入口：

```text
freefolio status -json
freefolio space list -json
freefolio doc list -json
freefolio format-guide
freefolio mcp
```

完整参数见 `freefolio help`。接口支持空间、文档、白板和数据库。窗口打开时，命令通过带随机凭据的回环地址接口作用于内存模型；文档和白板修改保留撤销。窗口关闭时，多个本地控制进程先取得系统文件锁，再读取配置与文件。

只读、锁定、输入法组合文本和外部修改保护仍有效。连接超时或鉴权失败不会退回另一个写入路径。删除先备份再进系统回收站。技能和 MCP 使用 FreeFolio 标识，不覆盖 ArcMD 的配置。

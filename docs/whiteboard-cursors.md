# 白板鼠标指针

指针表示当前鼠标位置可以执行的操作。按下后优先显示正在进行的操作；松手、取消或切换工具后重新判断。画布平移和缩放后，即使鼠标没有移动，也按新的内容位置更新指针。

| 场景 | 悬停时 | 按下或拖动时 |
| --- | --- | --- |
| 选择工具，空白画布 | 箭头 | 框选十字 |
| 可移动对象，包括多选中的对象 | 张开抓手 | 握紧抓手 |
| Alt 复制对象 | 复制 | 握紧抓手，移动副本 |
| 上下或左右缩放点 | 对应方向双箭头 | 保持对应方向 |
| 四角缩放点 | 对角双箭头 | 越过对边时切换对角方向 |
| 旋转点 | 张开抓手 | 握紧抓手 |
| 折线控制点或可插入点的线段 | 张开抓手 | 握紧抓手 |
| 文字工具或文字输入框 | I 形 | I 形 |
| 绘图、画笔、橡皮、套索、插入图片 | 十字 | 十字 |
| 抓手工具或按住空格 | 张开抓手 | 握紧抓手 |
| 中键或触控板平移 | 原工具指针 | 握紧抓手 |
| 滚轮、触控板或快捷键缩放 | 原工具指针 | 短暂显示放大或缩小，随后恢复 |
| Ctrl/Cmd 悬停有打开入口的对象链接 | 链接手形 | 打开链接 |
| AI 节点端口 | 十字 | 连接十字；不兼容目标显示禁止 |
| 可选择的 AI 连线或中央圆点 | 链接手形 | 选中连线并显示删除按钮，再次点击按钮断开；也可用 Delete 或右键断开 |
| 锁定对象，选择、文字或橡皮工具 | 禁止 | 不修改锁定对象 |
| 只读白板 | 箭头；链接仍可打开 | 保留平移和缩放 |

使用 MyGo 已提供的系统指针，不新增位图指针。MyGo v0.10.0 没有专用旋转指针，因此旋转沿用抓取和拖动的手形。指针语义参考 [W3C 预定义指针](https://www.w3.org/TR/css-ui-3/#cursor)。

## 命中与显示

- 缩放点、旋转点及折线控制点由显示、点击和指针共用命中规则。AI 节点隐藏的控制点不能成为不可见操作入口
- 旋转后的折线按旋转后的控制点位置命中，并将拖动坐标换回元素内部坐标；曲线采样点不作为可编辑控制点
- 图片标注的锁定底图仍可承载新文字和绘图，不因保护底图而禁用标注工具
- 工具栏、文字框、菜单、裁剪框和对话框使用自身指针。画布拖动期间保持当前操作指针
- Esc 或系统取消会撤销未完成的对象拖动并结束指针状态

## 核查与回归

2026-11-26 核查发现：选择工具未区分对象移动与控制点、文字工具显示十字、文字编辑框缺少 I 形、AI 不兼容连线未显示禁止、平移后静止鼠标仍沿用旧命中位置。上述路径已集中到 `internal/editor/board_cursor.go`，通过真实 `BoardView` 的无窗口交互测试采样最终指针。

回归覆盖框选后多对象移动与一次撤销、0.5/1/2 倍缩放下的九个控制点、工具切换、文字编辑、修饰键、锁定与只读、取消、平移后恢复、旋转曲线控制点及 AI 端口和连线。图片裁剪继续使用已有移动指针及四角方向指针。

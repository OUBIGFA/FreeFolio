# 字体、历史预览与笔记迁移

采用 Quiet.md 固定提交 `dfdf6da369eb0432a7f6c9024ca4f5c7605de4da` 的六项工作流，使用 FreeFolio 的 Go + MyGo 实现。来源见[第三方记录](../third_party/manifests/upstreams.json)。

## 工作区

侧边栏中，同一级的文件和文件夹名称对齐。每进入一层文件夹，子项向内缩进 16 个逻辑像素。当前文档保留选中底色，不加侧边竖线。

在工作区，当前文档和文件标签使用空间的强调色。关闭文档后，空间主页提供新建、搜索和本次会话最近打开的三篇本空间文档。命令栏保留所有匹配结果，可用方向键选择、Enter 打开。窗口窄于 720 个逻辑像素时，设置页将分类移到顶部菜单，给选项留出整行。工作区层级参考 [Linear 的界面改版](https://linear.app/now/how-we-redesigned-the-linear-ui)，设置分组参考 [Windows 设置设计指南](https://learn.microsoft.com/en-us/windows/apps/design/app-settings/guidelines-for-app-settings)。

## 字体

在 **设置 → 外观** 分别选择界面字体和正文字体。列表支持搜索、分类、收藏和最近使用。移动指针或按上下方向键临时预览，点击或按 Enter 保存；Esc、点击外部或“取消预览”恢复原字体。正文预览使用当前文档的独立只读副本。

可下载字体包括霞鹜文楷、朱雀仿宋和小赖手写体。选择下载项才联网；显示大小和进度，可取消。每个文件校验固定大小和 SHA-256，失败时保留原字体。缓存位于应用配置目录 `fonts/`，不进入空间或云同步。移除字体使用系统回收站，正在使用的字体恢复默认；已加载的数据可能保留到退出。旧版四类字体偏好继续有效。偏好格式升级到 17，其余设置不变。分类根据系统等宽属性和常见名称判断；未识别字体归入“其他字体”。[字体许可](../third_party/fonts/README.md)。

## 附件清理

在 **设置 → 空间 → 清理未使用附件…** 检查当前空间。检查默认 `assets/`、`.assets/` 或自定义附件目录，引用来自文档、白板、未保存内容、历史版本、FreeFolio 回收站、同步恢复副本、其他已登记空间和记住的本机文件。

检查保守保留出现过文件名的附件。读取失败会显示错误，不将未读内容当成空文档。选择后点击“移到回收站”并确认。执行时重新扫描引用并核对字节，先保存恢复副本，再进入系统回收站。回收失败保留原文件，没有自动永久删除附件的任务。

## 历史版本

“版本历史…”默认在正文区域预览历史排版，右侧列出版本。“显示改动”标出与当前版本不同的块；“文字差异”保留逐行、逐字比较。预览使用独立只读编辑器，不替换当前编辑器，不写回旧内容。返回后保留光标、滚动和撤销记录。“恢复此版本”仍为一个可撤销操作。命名里程碑与筛选保留。历史读取和比较在后台进行。

## 导入已有笔记

首次引导结束后可选择已有笔记，之后从 **设置 → 空间 → 导入已有笔记…** 打开。发现功能读取 Obsidian、Logseq、iA Writer、Typora 和思源的已知笔记位置；其他位置可以手动选择。

- Markdown 文件夹按原始字节和目录复制。单文件导入同时复制其明确引用、位于同一来源文件夹内的附件。应用配置和隐藏控制目录不复制，`.assets/` 除外。
- 思源支持工作空间、`data` 目录、笔记本目录和 ZIP 导出。先建立文档映射，再转换常见块、文档引用与附件。合并单元格和分栏通过现有转换入口成为可编辑结构。
- 属性视图转为静态表格；可明确定位的静态块查询复制内容，其余保留查询源码。无法精确定位的块引用转为文档链接并列入报告。
- 折叠状态、嵌套分栏、动态查询、挂件和其他不匹配格式按报告说明处理。未能读取的文档列为失败，不写成空文档。

每次建立新目标文件夹，不覆盖原文件或已有目标。报告区分文档、附件、转换项、失效引用和缺失附件。ZIP 拒绝越界、重复路径和符号链接；压缩包上限 256 MiB，展开总量 512 MiB，单文件 64 MiB。

## 快速笔记

在 **设置 → 通用 → 快速笔记** 选择保存空间、文件夹和全局快捷键。默认不开启全局快捷键；默认组合为 Windows/Linux 的 Ctrl+Shift+Space、macOS 的 Cmd+Shift+Space。应用必须运行；系统不支持或组合被占用时显示错误。托盘和设置页也提供入口。

笔记在独立小窗口中编辑，沿用保存、输入法、附件和冲突保护。关闭窗口按既有保存设置处理，不改变主窗口文档。默认文件夹为 `Quick Notes`，文件名不随界面语言变化。

## 同步合并

现有 WebDAV/S3 同步保存上次共同确认的 Markdown 或 `.arcmd` 内容。两台设备改动不同段落或不同嵌套内容时自动合并；同一段落、属性或删除与编辑冲突时继续保留两份。二进制附件不按文本合并。

合并检查活动编辑、输入法、只读、本地内容和远端版本。覆盖前保存恢复副本，远端使用条件写入。启用加密时，新基线也加密；更早的明文恢复副本和未引用基线不自动删除。旧版没有共同内容时保留冲突副本，不推断共同旧内容。

同步仍默认关闭，开启后不立即执行或补跑。此次没有新增 OneDrive、Google Drive 或 GitHub 服务。

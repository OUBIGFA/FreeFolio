# 白板模型参数

选中节点，点击「全部设置」。设置按内容、生成参数和生成细节分列完整展开，面板不滚动。点击运行后关闭面板，只有再次点击「全部设置」才打开。「恢复生成细节默认值」可重置种子、采样和引导设置。参数随白板保存，修改后重新运行会生成新结果。锁定节点或只读白板中的控件不可编辑。

## 常用参数

| 模型 | 可调整参数 |
| --- | --- |
| ACE-Step 1.5 Turbo | 速度 BPM、大小调、拍号、精确时长、种子、采样步数、引导强度；保留歌词与语言 |
| Stable Audio 3 Medium | 精确时长、种子、采样步数、引导强度、避免内容 |
| Qwen3-TTS CustomVoice | 语气与情绪、种子；保留音色与语言 |
| Wan 2.2 TI2V 5B | 横竖及方形尺寸、帧率、精确时长、种子、采样步数、引导强度、避免内容 |
| Z-Image Turbo 与对应 LoRA | 种子、采样步数、引导强度、避免内容；保留尺寸、画幅、数量与 LoRA 强度 |
| Qwen 2.1 普通版与对应 LoRA | 种子、采样步数、引导强度、避免内容；保留尺寸、数量与参考图 |
| Qwen 2.1 Turbo 与对应 LoRA | 种子、引导强度、避免内容；保留专用 8 步采样序列 |
| SeedVR2 3B / 7B | 种子、颜色校正；保留 2× / 4× 放大 |
| BRIA RMBG-3.0 | 种子、采样步数、引导强度；保留主体或材质说明 |
| Sa2VA 两款模型 | 抠图阈值；保留对象描述 |
| 已有 ComfyUI RMBG 节点 | 灵敏度、边缘柔化、边缘扩张 |

普通 BEN2、BiRefNet ONNX 和 Real-ESRGAN 路径也已核查：前两者是固定输入规格的自动抠图，不支持音乐式创作参数；后者已有模型和放大倍数选择。供应商图像和视频保留尺寸、数量、质量、时长等控件及实际透传的附加参数；文本模型默认沿用 OneBot 中对应连接的参数，也可在节点中单独覆盖已支持的参数。供应商是否接受某一参数仍由对应接口决定。

本地模型原来显示的「质量」和通用 JSON 控件没有进入本地工作流，现已隐藏。本地改用上述实际接入的控件。LoRA 的生成参数在最终生成节点设置，加载 LoRA 节点设置权重、连续强度和自动触发词开关。

## 音乐与广告 BGM

歌词留空且不连接歌词输入时生成纯音乐。BPM 默认 120，调性默认 C 大调，拍号默认 4/4；现在均可修改。调性列表包括原生节点支持的大小调和升降号写法，拍号支持 2/4、3/4、4/4、6/8。

时长可逐秒输入：音乐 5–120 秒，音效 1–60 秒，视频 1–5 秒。这些是当前应用的运行范围，不是模型能力上限。节点上的简略时长菜单也会显示自定义值。

ComfyUI 原生音乐节点要求明确的速度、调性和拍号，因此本次没有添加会提交空值的「自动」选项。较慢的 BPM 和小调可用于平静、悬念或沉郁方向，最终效果仍需试听。

## 默认与限制

- 种子填写 `-1` 使用原行为：生成模型随机，RMBG-3.0 和 SeedVR2 使用 42；填写非负整数则固定，0 也是有效值。同种子不承诺不同软件环境间逐字节一致。
- 「避免内容」在引导强度不为 1 时参与采样。设置为 1 时输入框禁用，原文字保留。清空视频的避免内容会发送空文本，不再恢复预设文字。
- 视频尺寸支持 832×480、480×832、640×640、1280×704、704×1280，帧率支持 12、16、24、30。帧数按 Wan 的 `4n+1` 布局向上对齐，实际时长可能略长于填写值。更高尺寸和帧率增加显存占用。
- Qwen Turbo 默认使用专用 8 步噪声序列，可在「更多模型参数」编辑完整序列，序列长度决定步数；不再额外设置一个相互矛盾的步数。SeedVR2 可在同一入口调整采样和 VAE 分块。文件格式、输出路径和模型文件由资源与附件管理负责。
- 切换模型时恢复采样、引导和避免内容的默认值；跨音视频模型同时恢复语言、时长、尺寸和帧率。歌词和音乐创作设置保留。旧白板缺少新增字段时继续使用原默认值。

## 核查依据与验证

核查使用当前锁定 ComfyUI 源码、已有 0.46.2 接口记录和固定的 QwenTTS 插件版本。ACE 元数据对应 `TextEncodeAceStepAudio1.5`，语气对应 `AILab_Qwen3TTSCustomVoice.instruct`，视频几何对应 `Wan22ImageToVideoLatent` 与 `CreateVideo`，颜色校正对应 `SeedVR2PostProcessing`。

参考：[ACE-Step 参数说明](https://github.com/ace-step/ACE-Step-1.5/blob/main/docs/en/INFERENCE.md)、[ComfyUI 原生节点](https://github.com/Comfy-Org/ComfyUI/tree/v0.46.0/comfy_extras)、[固定语音插件](https://github.com/1038lab/ComfyUI-QwenTTS/tree/d8122a8ba835b65fd65c113d2b273b1ad1579293)、[RMBG 控件定义](https://github.com/1038lab/ComfyUI-RMBG/blob/f871167b325835b627e233d5792c93f3cfb79b18/py/AILab_RMBG.py)。

测试检查实际控件编辑、撤销、锁定、白板保存与缓存失效，以及保存值进入原生请求。RMBG-3.0 另使用本机 ComfyUI 原生校验器验证：旧请求复现节点 6 缺少采样参数，修复后工作流校验通过，未执行推理。未调用供应商付费生成，也未执行新模型的 GPU 生成质量测试。

## 跟随输入图片

新建图像生成节点的画幅和尺寸默认设为「跟随输入图」。以第一张参考图为准，没有参考图时使用模型默认。手动选择尺寸或比例后按选择执行；旧白板已保存的明确尺寸保留。

本地 Qwen 2.1 保留输入像素，长边超过当前本地工作流的 2048 像素上限时等比例缩小，然后按模型 32 像素网格就近对齐。网格对齐可能产生少量比例误差，不裁剪内容。批量生成使用同样的尺寸。

Gemini 使用接口原生的输入图尺寸匹配，超大图使用支持的最高尺寸档位。支持任意尺寸的 GPT Image 2 系列按输入图宽高及接口上限缩放、对齐；只支持固定尺寸或未公布尺寸范围的供应商使用原生自动尺寸，不发送猜测的任意宽高。这些接口可能返回近似比例，FreeFolio 不拉伸生成结果来伪造精确比例。

尺寸依据：[OpenAI 图像尺寸限制](https://developers.openai.com/api/docs/guides/image-generation)、[Gemini 图像生成](https://ai.google.dev/gemini-api/docs/image-generation)。GPT Image 2 系列同时检查长边、像素总数、比例与 16 像素网格，小图按最低像素数等比例放大。

| Z-Image 普通版 INT8 / BF16 / GGUF Q8_0 | 采样器、调度器、降噪强度、采样偏移、编码器运行位置、CFG 归一化强度和归一化阶段；Safetensors 可调加载精度，GGUF 可调解量化精度、补丁精度和补丁运行位置 |

| Wan 2.2 | 采样器、调度器、降噪、偏移、加载精度、编码器运行位置、VAE 分块尺寸、重叠、时序分块及重叠 |

引擎已经连接时，使用其实际输入定义补齐采样器选项、范围和额外标量参数；只打开白板或设置不会启动或重新连接引擎。离线时显示已核查的工作流参数。来自引擎的新字段可能沿用原生英文名称。缺少所需节点、无效选项或保存了当前工作流不支持的参数时明确报错，不忽略它们。

「加载底模」可设置加载参数，经模型线传到最终生成节点；最终生成节点的明确设置优先。LoRA 的采样与生成参数在最终生成节点调整，因为多个 LoRA 共用一次生成。Turbo LoRA 不能直接接到 Z-Image 普通版，兼容性检查不会自动换底模。

普通版默认 40 步、CFG 4；Turbo 旧白板保留原默认。采样步数输入范围为 1–10000、CFG 为 0–100，极端值不代表适合所选模型。CFG 归一化通过 ComfyUI 原生 CFGNorm 节点执行，强度 0 关闭。高分辨率、多图、较大 VAE 分块和驻留显卡会增加显存需求。批量、时长与图像尺寸继续受本文列明的应用资源范围约束。

BEN2、BiRefNet ONNX 固定模型输入与现有透明度处理，没有扩散采样参数；ComfyUI 原生 Real-ESRGAN 节点没有额外标量参数。供应商图像和视频继续提供协议对应的尺寸、质量、数量、时长和附加 JSON 参数。任意模型文件、输出路径、内部连线和安装资源不作为自由输入参数。

依据：ComfyUI v0.46.0 的原生节点定义、已锁定语音插件高级节点、ComfyUI-GGUF 固定版本，以及 Real-ESRGAN ncnn 官方命令行说明。新增测试覆盖请求参数、参数持久化、上游缓存失效、只读与撤销、全部高级参数页面的小窗口边界及固定 GGUF 组件迁移。测试不调用供应商付费生成，不替代逐款模型的 GPU 出图、显存和画质验收。

条件参数随主开关禁用：关闭语音随机采样后，温度和 Top-p／Top-k 保留数值但不可编辑；关闭音频编码或描述采样时，所属采样参数同样禁用。文本节点的思考长度仅在推理开启时可调整。

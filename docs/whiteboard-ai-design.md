# 白板 AI 工作流设计

状态：已实现。依据《FreeFolio 白板 AI 升级开源调研报告》（2026-11-25）和用户确认的取舍；节点交互于同日按 LiteGraph 重做。

## 目标

可选的本地抠图节点使用一张输入图片，输出透明 PNG。模型选择、下载、保存位置和删除见[可选资源](optional-resources.md)。

在原生白板内直接调用 OneBot：用户自由拖动、连线、框选文字、图片、笔记和手绘标注，组合成文本、图像和视频的生成或编辑流程。结果写回白板，可撤销、可缓存、可分支对比。

用户确认的取舍：

| 问题 | 决定 |
| --- | --- |
| 界面形态 | 白板内节点卡，交互对标 ComfyUI：类型槽位、节点内直接编辑、连线与白板线条分离；文件仍是标准 Excalidraw 场景 |
| 复用对象 | 移植 ComfyUI 图核心 LiteGraph（Comfy-Org/litegraph.js，MIT）的连线规则；不嵌入网页，不使用 ComfyUI 前端（GPL-3.0） |
| 旧箭头连线 | 项目在开发阶段，不兼容：箭头只是白板图形，不再作为节点输入 |
| 独立绘画供应商 | 首批支持 OpenAI 兼容 Images / Videos API（OpenAI、new-api / one-api 中转、xAI 等） |
| 视频 | 纳入视频生成 |
| 复用方式 | 用户交由实现决定：协议按 OpenAI 官方接口实现，并与 LiteLLM、new-api 的兼容约定对齐；不新增依赖 |

## 方案取舍

| 方案 | 收益与限制 | 决定 |
| --- | --- | --- |
| AI 节点使用带 `customData.freefolioAI` 的 Excalidraw 元素，生成节点为矩形，图片输入节点保留图片元素；连线存在目标节点的 `links` 中 | 复用分组、画框、撤销和保存；连线不是白板元素，不会被当作白板线条选中、改样式或导出为箭头；外部 Excalidraw 可读取原有元素 | 采用 |
| 箭头即数据线 | 节点连线与白板线条混在一起，拖出的线变成可编辑的白板箭头 | 已弃用 |
| 嵌入 ComfyUI / LiteGraph 网页 | 体验一致，但需要 WebView，违反纯 Go 约束 | 不采用；按模块移植规则 |
| 另建 AI 工作流文件类型与节点编辑器 | 交互更像 Vibe-Workflow，但与白板割裂，需重写选择、连线和保存 | 不采用 |
| 依赖 go-openai 处理 Images API | 不支持多图编辑；项目其余协议均为纯 Go 直连 | 不采用；按官方接口直连 |
| 引入通用 DAG 库 | 白板图通常 2–50 个节点，需与场景、主线程和流式回调深度耦合 | 不采用；自研小型调度器 |

## 数据模型

节点保存在元素的 `customData.freefolioAI`，保留其他命名空间：

```json
{"freefolioAI": {"v": 1, "role": "text", "connection": "id", "model": "gpt-5",
  "instruction": "总结要点", "params": {"size": "1024x1024", "count": 1},
  "links": [{"slot": "prompt", "from": "元素 ID"}, {"slot": "text.0", "from": "元素 ID"}],
  "inputHash": "sha256:…", "error": "", "current": 0,
  "outputs": [{"kind": "text", "text": "…"}, {"kind": "image", "path": "assets/ai-1.png"}]}}
```

| 角色 | 输入 | 输出 |
| --- | --- | --- |
| `image-input` 图片输入 | 已导入图片的附件引用 | 原图片；不调用生成服务 |
| `text` 文本生成 | 文本、图片、画框、笔记、上游节点 | 文本；可写回上游文本或生成便签 |
| `image` 图像生成/编辑 | 提示词；接入参考图时改图；「遮罩」槽位作遮罩 | 1–4 张图片 |
| `video` 视频生成 | 提示词；可选首帧图片 | 视频文件 |
| `concat` 提示词拼接 | 文本 | 按模板 `{1}`、`{2}` 拼接的文本 |
| `note` 笔记引用 | `[[文档]]` | 文档正文 |

- 每个节点有类型槽位（`internal/whiteboard/aigraph.go`）。类型为 `STRING`、`IMAGE`、`VIDEO`：

  | 角色 | 输入槽位 | 输出 |
  | --- | --- | --- |
  | 文字节点 | 无 | `STRING` |
  | 图片输入 | 无 | `IMAGE` |
  | 笔记引用 | 无 | `STRING` |
  | 文本生成 | 指令（`STRING`，对应节点内指令框）、文本 ×n、图片 ×n | `STRING` |
  | 加载底模 | 无 | `MODEL` |
  | 加载 LoRA | 模型（`MODEL`） | `MODEL` |
  | 图像生成 | 提示词（`STRING`，对应指令框）、参考图 ×n、遮罩、模型（ComfyUI） | `IMAGE` |
  | 图片增强 | 输入图片（`IMAGE`，一张）、增强说明（`STRING`） | `IMAGE` |
  | 视频生成 | 提示词（`STRING`，对应指令框）、首帧 | 无 |
  | 提示词拼接 | 文本 ×n | `STRING` |

- 连线规则移植 LiteGraph：类型按 `isValidConnection` 匹配；一个输入只接一条线，新线替换旧线（`connectSlots`）；一个输出可接多条线；落在节点主体时进入第一个空闲的同类型槽位（`findFreeSlotOfType`）；会形成循环的连线被拒绝。
- 「×n」是可增长列表：已连接的槽位后始终留一个空槽位，最多 8 个；断开中间一个时后面的前移。
- 指令槽位连接后，上游文本代替节点自己的指令，节点内和属性面板的指令框都置灰禁用，显示「已连接：来源」，与 ComfyUI 的控件输入一致。断开后恢复原指令。
- 模型选项标明「本地模型」或「供应商模型」。不接收提示词的抠图模型禁用输入框和提示词槽位；历史文字和连线保留，禁用连线不显示、不读取、不调度上游，切回支持提示词的模型后恢复。图片放大仍仅接受图片输入。
- 白板元素也可作来源：文字、带文字的图形和便签提供文字；图片提供图片；画框提供框内内容的 PNG 及框内文字（标注改图）；带 `[[文档]]` 链接的元素提供笔记正文。直线、箭头和手绘笔迹不能作来源。
- 选中已导入图片后，可在浮动工具条或右键菜单中选择「转为节点」。转换保留元素 ID、附件引用、裁剪、翻转和已有连线，卡片围绕原中心展开并取消旋转；可撤销。图片输入节点显示原图片预览，右侧 `IMAGE` 输出可拖到图像生成节点的「参考图」或「遮罩」，也可连到文本节点的「图片」及视频节点的「首帧」。单独运行下游或连同上游运行均直接读取原附件，不生成或复制输入图片。
- 复制粘贴节点时只保留复制范围内部的连线；删除来源后连线失效，撤销删除后恢复。
- 生成的图片和视频经 `writeAssetFor` 写入空间附件目录，节点只记录相对路径，不把大文件嵌入白板。「放到白板」把当前结果作为普通元素放在节点右侧，不画连线。
- 图像生成节点的历史、当前参考图和节点内 A/B 滑杆对比见 [图片历史与对比](whiteboard-image-history.md)。下游仅使用当前选择显示的一张图，重新生成的多图批次默认使用第一张。
- 运行状态（排队、生成中、流式文字）只在内存中，不写入文件；完成后写入输出、输入哈希和错误，作为一次可撤销修改。

## 执行

- `internal/whiteboard/aiflow.go`：读取节点、解析输入、环检测、拓扑分层、`context` 级联取消、最多 4 个并发；上游失败时下游标记为未运行。
- 增量缓存：输入哈希由节点配置与全部输入内容（图片按字节哈希）计算。哈希未变且已有输出时跳过，「强制重新运行」除外。
- 运行范围：单个节点、节点及其上游、全部节点。

- 新 LoRA 流程使用 `model → lora → image/enhance` 角色和 `MODEL` 类型连线。LoRA ID 存于加载 LoRA 节点的 `model`，`params.loraStrength` 保存强度；缺省使用清单初始值，显式 0 关闭。执行时从场景快照解析底模与有序 LoRA 链，纳入下游缓存哈希；仅运行最终节点也会读取配置链。模型节点不写图片或文本结果。旧单节点预设兼容保留。
- 本地工作流在 `UNETLoader` 后插入 `LoraLoaderModelOnly`，所有采样与缓存节点使用加载 LoRA 后的模型。运行前检查资源 ID、底模家族、文件名和本地 SHA-256；不支持或缺少资源时不提交生成请求。

## OneBot 多模态输出

`internal/agent/media.go` 增加图像与视频生成：

| 协议 | 图像 | 视频 |
| --- | --- | --- |
| 新增「OpenAI 兼容图像/视频」 | `/images/generations`、`/images/edits`（多图、遮罩） | `/videos` 提交、轮询、下载 |
| OpenAI Responses | 内置 `image_generation` 工具 | 同服务地址的 `/videos` |
| OpenAI Chat Completions | 同服务地址的 `/images/*`；OpenRouter 使用 `modalities` | 同服务地址的 `/videos` |
| Google Gemini | `responseModalities: ["TEXT","IMAGE"]`；`imagen-*` 使用 `:predict` | Veo `:predictLongRunning` 轮询并下载 |
| ChatGPT 套餐、Anthropic、Ollama | 不支持，明确报错 | 不支持 |

下载结果限制大小，只接受 http(s)；鉴权头不转发给其他主机。错误沿用现有密钥脱敏。

## 界面

层级与操作对标 ComfyUI，样式沿用 FreeFolio 主题：

- 节点卡自上而下：标题栏（类型图标、名称、右侧运行或停止按钮）→ 槽位行（左侧输入、右侧输出，带标签）→ 节点内控件（指令/提示词输入框、模型、常用参数）→ 结果区（文字、图片、视频；多张图片时结果区下方紧跟历史与 A/B 对比栏）→ 状态行（状态、结果序号）。
- 节点内控件是真实控件，按卡片尺寸布局并随画布缩放，平移、缩放、框选或拖动时始终显示，不再闪烁。缩放低于 30% 时绘制控件的当前值。
- 指令框、模型和参数行按实际高度预留空间，参数行与结果区之间保留间距，比例、尺寸、数量与质量不覆盖图片；连接上游提示词后仍保持这一边界。
- 节点类型、运行、停止与预览图标使用 SVG，紧凑图标在 100% 白板缩放下为 16 像素。图标按显示尺寸重新绘制，普通画布和密集场景缓存均传入各自的实际缩放比例，避免放大低分辨率图标。
- 槽位按类型着色：已连接为实心，空闲为空心。拖线时不能接收的槽位变淡，吸附目标显示光晕。
- 连线是三次贝塞尔曲线，画在白板内容之上、节点卡之下。中点采用 LiteGraph 的圆点标记；鼠标可点击的区域保持固定大小，不随缩小而难以点击。悬停时圆点出现外环，点击圆点选中连线并显示删除按钮，再次点击按钮断开连线。点击空白处取消选中并恢复圆点。选中后也可按 Delete 或右键选择「删除连线」断开，可撤销；只读白板与锁定节点不可删除连线。
- 拖线：从输出拖到其他节点的输入或节点主体；从空闲输入反向拖到节点输出、便签、图片或画框；从已连接的输入拖动会拾起这条线，放到空白处即断开。新线放到空白处弹出可接入的节点类型，新节点的槽位对齐松手位置。
- 选中节点时上方浮出工具条：「全部设置」「连同上游运行」、结果翻页、复制、放到白板。「全部设置」打开右侧属性面板，含名称、全部参数、输入列表（可逐个断开）和结果操作。
- 工具栏「AI」按钮打开左侧节点栏：输入、文本、图像、视频、模板，可搜索。选中普通元素时出现「AI 文本」「AI 生图」「AI 视频」，自动建节点并把选中内容接入素材槽位（不占用指令槽位）。
- 白板中的 OneBot 对话获得白板工具（读取、建卡、改字、连线、建 AI 节点、运行节点、排列），每次修改可撤销。
- 支持导入/导出 JSON Canvas（`.canvas`）；节点连线导出为带槽位名的边。
- 空、加载、错误状态都有文字说明；键盘可操作；减弱动态效果时不播放加载动画。

## 设置

- 新增协议「OpenAI 兼容图像/视频」与预设「OpenAI 绘画」，可只用于图像或视频。获取模型后按能力标记图像、视频输出，可手动校正。
- `prefs.json` 升至第 15 版，记录白板 AI 默认的文本、图像、视频连接与模型；旧版本零值迁移。
- 图像专用连接不能用于普通对话，选中时说明原因。

## 使用

1. 打开白板，点击工具栏的「AI」按钮，在左侧节点栏选择节点或模板。
2. 在节点卡上直接选择模型、参数，填写指令，点击「运行」。
3. 从节点右侧输出拖线到另一个节点：落在具体槽位上就接入该槽位，落在节点主体上就接入第一个同类型的空闲槽位。也可以从输入反向拖到便签、图片或画框。
4. 把文字节点连到图像生成的「提示词」后，图像节点的指令框置灰，运行时使用文字节点的内容。
5. 要断开连线，可以点击中点圆点，再点击出现的删除按钮；也可从输入把线拖到空白处，或单击连线后按 Delete。
6. 也可以先框选内容，在选区上方点击「AI 文本」「AI 生图」或「AI 视频」，自动建节点并连线。
7. 结果显示在节点中。选中节点后可翻看历史结果、播放视频，或点击「放到白板」。

画框作为输入时，框内内容以图片发送，框内文字作为标注说明。

在白板中打开 OneBot 对话时，OneBot 可以读取白板、添加卡片和 AI 节点、连线、排列和运行节点；每次修改都可撤销。

## 与外部工具的兼容

- 外部 Excalidraw 打开文件时，生成节点显示为普通矩形，图片输入节点仍为图片，`customData` 原样保留。
- 节点的指令和文字结果进入搜索、双链摘要和 OneBot 问答。
- 「导出 JSON Canvas…」输出节点、文字、文件链接、分组和连线；手绘路径和样式不导出。

## 验证

- 协议：本地 `httptest` 覆盖各协议的请求体、多图编辑、轮询、下载与脱敏。
- 白板：槽位与连线规则（类型匹配、找槽、替换、列表增长与收拢）、输入解析、环检测、粘贴重映射、缓存命中、取消、上游失败、JSON Canvas 往返。
- 界面：`ui.NewTester` 覆盖添加节点、输出拖线与新节点菜单、反向连线、指令框置灰、拾起断开、中点先选中再点击删除、取消选中、Delete 与右键删除、只读与锁定保护、类型与循环拒绝、框选和平移时控件保持、控件随缩放、撤销和属性面板。
- 真实供应商的联网调用取决于账号和模型，未在自动测试中验证。

### 本地音视频

`audio` 角色保存音频附件，输出类型为 `AUDIO`，不作为文本或图片传递。`params.lyrics`、`speaker`、`language` 与现有 `seconds` 保存生成设置。歌词输入仅在 ACE-Step 模型启用，连接后覆盖本次请求的歌词并纳入缓存哈希，不改写保存的原歌词。语音与音效停用歌词上游调度。

`comfyui-media` 连接按模型清单构建 ACE-Step、Stable Audio、Qwen3-TTS 或 Wan 工作流。结果通过原有附件写入路径保存，FLAC/MP4 必须有对应格式标记。缺少节点、无输出、错误结果和取消都返回实际错误。语音插件仅由资源下载动作安装，不在生成时安装。

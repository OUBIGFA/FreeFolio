# 界面设计规范

本文件是 FreeFolio 编辑器以外界面的设计基准。新增或调整界面时，按本文件的令牌、组件和检查项实现，再用快照核对。通用原则来自 `visual-design` 技能；本文件写明它在 FreeFolio 中的具体取值和例外。两者冲突时，以本文件和 `AGENTS.md` 为准。

## 适用范围

- 适用：`internal/app` 与 `cmd/freefolio` 的全部界面，包括标题栏、侧边栏、设置、命令栏、新建栏、空间库、OneBot 面板、各类弹窗、浮层、提示条和首次引导。
- 不适用：文档正文、白板、数据库视图、思维导图（`internal/editor`、`internal/editor/dbview`、`internal/mindmap`）。正文纸面使用 `documentTheme` 与 `pageStyle`，不跟随本规范调整。

## 设计令牌

所有令牌集中在 `internal/app/theme.go`。界面代码不直接写颜色值；需要新颜色时，先在 `theme.go` 加令牌。

### 颜色

界面约 90% 的面积使用中性色。强调色只有一种：当前空间的颜色，由 `spaceAccent` 换算成统一明度。强调色只用于核心操作（主按钮、开关）、当前选中项和关键数据。

| 令牌（`neutralTheme`） | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `Background` | `#F5F5F5` | `#161616` | 窗口底色（chrome） |
| `Surface` | `#FFFFFF` | `#232323` | 设置面板、弹窗、卡片 |
| `SurfaceHover` | `#EBEBEB` | `#2E2E2E` | 悬停、选中的中性底色 |
| `SurfacePressed` | `#E0E0E0` | `#383838` | 按下 |
| `Border` | `#D6D6D6` | `#3A3A3A` | 输入框、浮层的细边 |
| `Text` | `#181818` | `#EDEDED` | 主文字 |
| `TextMuted` | `#6A6A6A` | `#A0A0A0` | 次要文字 |

- 浅色窗口底色上的次要文字用 `#666666`（`lookOf`）。原因：`#6A6A6A` 在灰底叠加选中色时低于 4.5:1，由 `TestSpaceChromeContrast` 检查。
- 选中行的强调色底色不超过 10% 不透明度（`t.Accent.Alpha(0.10)`）。
- `Danger`、`Warning`、`Success` 只用于表示状态，不作装饰。
- 禁止渐变、毛玻璃、高饱和色和霓虹色。

### 圆角

| 常量 | 值 | 用途 |
| --- | --- | --- |
| `controlRadius` | 8 | 按钮、输入框、行、提示条 |
| `panelRadius` | 16 | 面板、卡片、提示框、设置面板 |
| `dialogRadius` | 24 | 命令栏、新建栏等浮动对话框 |

圆角取值范围为 8–40；胶囊形用 `Radius(999)`。

### 阴影

- 原位放置的卡片和面板不用阴影。
- 只有浮在内容上方的元素用阴影：菜单、浮层、弹窗、拖动中的行和提示。写法统一为 `Shadow(0, 8, 24, 0, floatShadow(t))`，每个元素只有一层。

### 间距

- 所有字面间距（`Padding*`、`Margin*`、`Gap`）取 4 的整数倍。
- 按窗口尺寸计算的间距用 `grid4(...)` 向下取整到 4 的倍数。
- FreeFolio 自己的间距是常规取值的 1.5 倍。常用档位：4、8、12、16、20、24、32、48。
- MyGo 的 `Theme.Spacing` 保持默认值 4（`chromeSpacing`）。原因：MyGo 用同一单位决定复选框、滑块、取色器和表格行的尺寸，调大会放大控件本身，而不是控件周围的留白。

### 字体

| 层级 | 字号 / 字重 | 颜色 |
| --- | --- | --- |
| 页面标题（`settingsHeading`） | 24 / 600 | `Text` |
| 分组标题（`settingsSection`） | 15 / 600 | `Text` |
| 行标签、列表项 | 14 / 400 | `Text` |
| 行内数据、说明 | 13 / 400 | `TextMuted` |
| 徽标、计数 | 12 / 500 | 对应色 |

标题加粗、加深；正文用常规字重和更浅的颜色。字重不超过 600，不用小于 11 的字号。

## 布局规则

- 一个区域只有一层表面。设置页只有右侧白色面板这一层；`settingsGroup` 不画边框和底色。
- 不嵌套卡片。弹窗内的分组用底色深浅区分，不再加边框。
- 有底色的元素不同时加边框；浮层和输入框除外。
- 不加分割线，用留白分组。`settingsSeparator` 已改为不绘制，新代码不要再调用它。
- 不用“底色方块 + 图标”的装饰图标块。图标直接放在 24×24 的透明区域中。
- 设置页的行与页面标题左对齐，不加左右内边距：
  - `settingRow(c, key, label, note, control)`：常规行。`note` 只作为悬停提示和无障碍描述，不在页面上显示。
  - `settingDetailRow(c, key, label, detail, control)`：标签下方常显一行，只用于数据（路径、账号、状态）、警示和控件不可用的原因。
  - `toggleRow`：开关行，`note` 的规则同 `settingRow`。
- 有底色的提示条（`settingsBanner` 或带色条）使用 `controlRadius`，内边距为 `Padding(12, 16)`。

## 文案

- 不写标语、副标题、页面说明、次级标签和键盘提示条。
- 下列内容保留在页面上：风险、限制、不可逆后果、错误原因、费用提示、隐私提示，以及控件不可用的原因。
- 对理解有帮助的解释改为悬停提示，并用 `.Description(...)` 提供给辅助技术。
- 空状态只显示一行状态文字和对应操作，不写引导段落。
- 可选资源保留用途、大小、依赖和限制（见 `AGENTS.md`）。
- 删除界面文字后，同步删除 `internal/i18n/en_*.go` 中的译文，并运行 `gofmt` 和 `go test ./internal/i18n`。

## 交互

- 次要操作按意图显示：用 `revealOnIntent(row, actions)`。指针悬停在行上或键盘焦点进入行内时才显示，控件仍保留在 Tab 焦点顺序中。现有示例：空间列表的编辑、显示、移除按钮，空间库卡片的拖动和菜单，OneBot 历史中的删除按钮。
- 多级菜单使用 MyGo 的 `Menu.Submenu`。MyGo 已实现安全三角区，并在指针朝子菜单移动时保持子菜单打开 300 ms（`menuAimGrace`）。MyGo v0.10.0 没有开启延时；在不修改依赖的前提下，这一项暂不实现。
- 标题栏和侧边栏工具栏的图标按钮为 30×30，彼此间距为 0。图标本身已有留白，这样标题才能在窄窗口中保持居中。客户端窗口按钮的间距为 8，宽度常量是 `windowButtonsWidth`。

## 动效

- 时长 150–250 ms，曲线为 `ui.EaseOut` 或线性。
- 不用弹簧回弹、放大弹出或悬停上浮。入场位移不超过 8 DIP，缩放不小于 0.96（参见 `toastEnter`、`bannerEnter`）。
- 遵守系统的“减弱动态效果”设置（`motionReduced`）。

## 已知例外

| 位置 | 例外 | 原因 |
| --- | --- | --- |
| 白板 AI 模型选择器 | 绿、紫、蓝圆点 | `AGENTS.md` 规定用来区分本地、ComfyUI 和供应商 |
| 侧边栏未保存文档 | 行尾圆点 | 沿用系统惯例；标题栏同时显示“已修改”文字 |
| 首次引导 | 快捷键提示块 | 教学内容本身 |
| 侧边栏横向溢出 | 同色透明渐隐 | 提示内容可滚动，不是装饰性渐变 |
| 源码分栏、侧边详情 | 分隔线 | 可拖动或表示边界，有实际功能 |

## 验收

1. 生成快照：把 `FREEFOLIO_SNAPSHOT` 设为仓库内 `_temp/shots` 的绝对路径，运行 `CGO_ENABLED=0 go test ./internal/app -run Snapshot`。
2. 至少查看受影响界面的浅色、深色和窄窗口快照，逐项核对：
   - 与页面标题左对齐，没有残留的旧内边距；
   - 没有文字被截断、换行异常或遮挡；
   - 没有套框、分割线或装饰图标块；
   - 强调色只出现在核心操作和选中项上。
3. 标题栏、设置页和 OneBot 面板有几何断言测试，例如 `titlebar_test.go`、`TestFixedSettingsFitMinimumWindow`、`TestOneBotCardMatchesEditorCardHeight`。调整间距导致这些测试失败时，先判断是否违反了其约束（可达、居中、最小窗口可用）。只有确认是本次有意的间距变化时，才更新测试的取值。
